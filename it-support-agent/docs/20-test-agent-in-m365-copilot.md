# Microsoft 365 Copilot でエージェントをテストする

作成したエージェントを公開し、Microsoft 365 Copilot から利用できるようにして、テストします。

1. エージェント デザイナーのツールバーにある [Publish] をクリックします。

2. [Publish] ダイアログで [Add channel] > [Teams + Microsoft 365] をクリックします。

3. [Microsoft 365 Copilot only] を選択して、[Add channel] をクリックします。

4. [Publish agent] をクリックします。

5. 公開プロセスが完了するまで待ちます。公開が成功すると、ダイアログにその旨が表示されます。

6. 公開成功のダイアログ上の [Share] をクリックします。

7. [Share <エージェント名>] ダイアログの下部の [Copy link (Microsoft 365 Copilot)] をクリックして、リンクをコピーします。

8. コピーしたリンクをブラウザーで開きます。

9. エージェントの追加ダイアログが表示されたら、[追加] をクリックします。

10. エージェントが追加されたら、メッセージを入力してテストします。
