# 出張申請チェック エージェント

## 概要

このハンズオンでは、Microsoft Copilot Studio を使用して、架空の企業における出張申請を社内規定に基づいてチェックするエージェントを作成します。

エージェントの作成を通じて、Microsoft Copilot Studio の基本的な操作方法や、ファイルから情報を抽出してチェックを行う方法について学習します。

> [!IMPORTANT]
>
> 本ハンズオンでは、GitHub Copilot harness で動作するエージェントを作成します。
>
> GitHub Copilot harness で動作するエージェントは、使用量に基づく請求が行われ、Copilot クレジットを消費します。
>
> これは、エージェントの構築、テスト、評価、実行に適用されます。

## 前提条件

- エージェントを作成する Power Platform 環境が準備されていること
- 利用する環境で Copilot クレジットを利用できること

> [!NOTE]
> 
> このハンズオンでは、エージェントの作成手順のみを説明しています。
>
> Power Platform 環境の作成やエージェントの公開などの手順については説明していません。
>
> 必要に応じて、[IT サポート エージェント](/it-support-agent/README.md) を参照してください。
